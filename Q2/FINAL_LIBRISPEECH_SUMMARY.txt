HOW IT WORKS
================================================================================

UNIFIED DATASET ABSTRACTION:
Both LibriSpeech and VoxCeleb now expose identical interface:

  Batch dictionary:
    - 'features': torch.Tensor (80, 300) - mel-spectrogram
    - 'speaker': int - speaker ID
    - 'session': int - session/chapter/video ID (used as env proxy)
    - 'utt_path': str - path to utterance file

  VoxCeleb example:
    speaker=2000, session=video_id_12345
    
  LibriSpeech example:
    speaker=121, session=chapter_id_180298

TRAINING COMPATIBILITY:
Training loops use generic 'session' key:
  env_labels = batch['session'].to(device)

This works identically for both datasets!

AUTOMATIC DETECTION:
Config file specifies which dataset to load:

  data:
    dataset: "librispeech"  # loads LibriSpeechDataset
    train_root: "/csehome/m25csa028/Q2"
    subset: "train-clean-100"

OR:

  data:
    dataset: "voxceleb"     # loads VoxCelebDataset
    train_root: "/path/to/voxceleb"

FEATURES

✅ FLAC Support
  - LibriSpeech uses FLAC (lossless)
  - Automatic decoding via torchaudio.load()
  - No manual conversion needed

✅ Session-based Batching
  - chapter_id acts as session proxy
  - Similar to video_id in VoxCeleb
  - Maintains speaker/environment separation

✅ Mel-Spectrogram Features

  - 300 frames (~3 seconds)
  - Extracted on-the-fly during training

✅ Automatic Speaker Detection
  - Scans LibriSpeech directory structure
  - Counts speakers and utterances
  - Configures discriminators accordingly

✅ Backward Compatibility
  - VoxCeleb configs still work
  - Same training code supports both
  - No breaking changes to existing setup

================================================================================
CONFIGURATION PARAMETERS
================================================================================

dataset: "librispeech" | "voxceleb"
  - Type of dataset to load

train_root: "/path/to/data"
  - Parent directory containing dataset
  - For LibriSpeech: parent of LibriSpeech/ folder
  - For VoxCeleb: parent of ID* folders

subset: "train-clean-100" | "train-clean-360" | "train-other-500"
  - LibriSpeech subset (only relevant if dataset="librispeech")
  - Default: "train-clean-100"

batch_size: 128
  - Batch size for training
  - Reduce to 64 or 32 if CUDA OOM

num_utterances_per_speaker: 2
  - Utterances per speaker per batch
  - Affects triplet batch construction

num_speakers_per_batch: 50
  - Number of speakers per batch
  - Total batch = num_speakers * num_utterances_per_speaker

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "LibriSpeech dataset not found"
Solution:
  cd /csehome/m25csa028/Q2
  ./setup_librispeech.sh
  # OR manually:
  tar -xzf train-clean-100.tar.gz

Issue: "CUDA out of memory"
Solution: Edit config, reduce batch_size:
  data:
    batch_size: 64  # from 128

Issue: "moduel torchaudio not found"
Solution: Install dependencies
  pip install torch==2.1.0 torchaudio==2.1.0

Issue: "Epoch 1 very slow, others fast"
Solution: This is normal! FLAC decoding on-the-fly is slower first epoch.
  - First epoch: slow (decoding + feature extraction)
  - Later epochs: faster (OS caching)

Issue: "Wrong speaker count"
Solution: Verify tar extraction:
  ls -la LibriSpeech/train-clean-100/
  # Should show: 121/, 1221/, 1320/, 1602/, 1673/, 1701/, ...
