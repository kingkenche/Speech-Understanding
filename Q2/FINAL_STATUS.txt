REPRODUCTION INSTRUCTIONS
================================================================================

Quick Start (15 minutes with synthetic data):
```bash
cd q2
pip install torch==2.1.0 torchaudio==2.1.0 pyyaml scipy numpy
python train.py --config configs/baseline.yaml
python eval.py --config configs/baseline.yaml \
    --checkpoint checkpoints/baseline/best.pt \
    --eval_dir /tmp/dummy --trial_file /tmp/dummy.txt \
    --output results/demo.json
```

Full Reproduction (48+ hours with VoxCeleb2 + A100):
1. Download VoxCeleb1-dev (~148k utterances)
2. Update config paths (train_root, test_root, trial_file)
3. Run: python train.py --config configs/baseline.yaml
4. Run: python train.py --config configs/disentangler.yaml --encoder_ckpt ...
5. Run: python train.py --config configs/vae_improved.yaml --encoder_ckpt ...
6. Run: python eval.py for each model on test set
7. Run: python generate_plots.py to visualize results

See q2/README.md for detailed instructions
