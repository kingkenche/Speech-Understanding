# Q3 – Ethical Auditing & Documentation Debt Mitigation

A **Sound Check** pipeline for identifying social biases in public audio datasets,
preserving speaker privacy through voice attribute transformation, and training
fairer ASR models with a custom fairness loss.

---


## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run Bias Audit (demo – no dataset needed)

```bash
python audit.py --demo --output_dir audit_output
```

With a real Common Voice directory:
```bash
python audit.py --data_dir /path/to/cv-corpus-en --output_dir audit_output
```

**Outputs:** `audit_output/audit_plots.pdf`, `audit_report.csv`, `bias_scores.json`

---

### 3. Run Privacy-Preserving Transformation Demo

```bash
# Synthetic audio (no files needed)
python pp_demo.py --output_dir examples/

# Your own audio file
python pp_demo.py \
    --input_wav your_voice.wav \
    --source_gender male   --source_age old \
    --target_gender female --target_age young \
    --output_dir examples/

# Run all transformation pairs
python pp_demo.py --all_pairs --output_dir examples/
```

**Outputs:** `examples/source.wav`, `examples/transformed.wav`, comparison plot PNG, `transform_metrics.json`

---

### 4. Train Fair ASR Model

```bash
# Demo mode (synthetic data, fast)
python train_fair.py --demo --epochs 5

# With Common Voice data
python train_fair.py \
    --data_dir /path/to/cv-corpus-en \
    --output_dir checkpoints/ \
    --epochs 20 \
    --lambda_fair 0.5 \
    --batch_size 16

# Baseline (no fairness loss, for comparison)
python train_fair.py --demo --no_fair --epochs 5 --output_dir checkpoints_baseline/
```

**Outputs:** `checkpoints/best_model.pt`, `training_history.json`, `training_curves.png`

---

### 5. Run Evaluations (FAD + DNSMOS)

```bash
# Demo mode
python evaluation_scripts/fad_eval.py --demo
python evaluation_scripts/dnsmos_eval.py --demo

# On real audio directories
python evaluation_scripts/run_all_evals.py \
    --reference_dir examples/reference/ \
    --generated_dir examples/generated/ \
    --output_dir    eval_results/
```

**Outputs:** `fad_results.json`, `dnsmos_results.json`, `dnsmos_plot.png`, `combined_eval.json`

## Component Details

### `audit.py` – Bias Audit

Analyses a TSV-based audio dataset (Common Voice format) for:
- **Documentation Debt**: percentage of missing gender/age/accent metadata
- **Representation Bias**: normalised entropy, Gini coefficient, χ² uniformity test
- **Intersectional Bias**: gender × age cross-tabulation heatmap
- **Split Consistency**: checks train/dev/test have similar demographic distributions

Generates a 6-page `audit_plots.pdf` with all visualisations.

### `privacymodule.py` – Privacy-Preserving Module

A CycleGAN-inspired voice conversion model with:
- **ContentEncoder**: Strips speaker identity (strided convs + ResBlocks)
- **AttributeEncoder**: Global speaker style vector
- **TargetAttributeEmbedder**: Discrete gender/age → continuous embedding
- **Decoder**: AdaIN-based mel generation with target style injection
- **Discriminators**: PatchGAN + attribute classifier for adversarial training

Model size: ~3.2M parameters (lightweight for embedded deployment).

### `train_fair.py` – Fair ASR Training

- CTC-based ASR: ConvFeatureExtractor + 6-layer Conformer + CTC head
- **FairnessLoss**: Group-DRO-inspired penalty with EMA group tracking
  - Gap penalty: `λ_fair × (worst_group_loss − best_group_loss)`
  - Threshold penalty: `λ_reg × Σ max(0, group_loss − τ)²`
- 7 demographic groups (gender × age buckets from audit findings)

### `evaluation_scripts/fad_eval.py` – FAD

Computes Fréchet Audio Distance between reference and generated audio using
lightweight VGGish-proxy embeddings (128-dim). Includes interpretation thresholds.

### `evaluation_scripts/dnsmos_eval.py` – DNSMOS Proxy

Predicts SIG/BAK/OVR MOS scores (1–5 scale) non-intrusively. Also computes:
- Speech Activity Ratio (SAR)
- Zero-Crossing Rate (ZCR)
- STOI proxy (intelligibility, when reference is available)

## Ethical Considerations

1. **Dual-use**: Voice transformation could enable deepfakes. Production deployment
   requires consent frameworks, watermarking, and audit logging.
2. **Fairness trade-off**: λ_fair=0.5 reduces majority-group accuracy slightly
   (~3–5% relative WER increase) while closing the worst-group gap.
3. **Group definition**: Coarse gender/age bins may reinforce binary categorisation.
   Future work should use continuous latent representations.
4. **Data sovereignty**: Community consent should be obtained for any re-use of
   speaker recordings for transformation model training.

See `q3_report.pdf` for the full 4-page technical report.
